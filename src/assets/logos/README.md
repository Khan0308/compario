# Product logos

`<product-slug>.svg` (or .png / .webp) in this folder is used automatically as that product's logo.
The slug is the product name in lowercase with dashes, e.g. `google-drive.svg`, `premiere-pro.svg`.

- The SVGs here for 28 products use each brand's glyph and colour from the open-source Simple Icons set (CC0).
  The logos themselves remain trademarks of their owners; they are used here only to identify the product.
- Products without a file here (ChatGPT, Bluehost, Canva, Ahrefs, Salesforce, Slack, Premiere Pro,
  Final Cut Pro, ActiveCampaign) show a clean stand-in tile. To use the official logo, download it from the
  company's brand/press page and save it here with the matching slug. No code change is needed.
